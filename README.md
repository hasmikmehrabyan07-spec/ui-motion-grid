# UI Motion Grid

An interactive grid of **20 hover-to-reveal UI motion and loading animations** built with pure HTML, CSS, and vanilla JavaScript.

Each square card starts with a hidden, paused animation stage—showing only the index number and animation title—and smoothly reveals and plays the animation when hovered.

## Features

- **Hover-to-Reveal & Play:** Animations remain hidden (`opacity: 0`) and paused (`animation-play-state: paused`) at rest, then fade in and run on hover.
- **Glassmorphism UI:** Frosted dark cards with subtle glow accents and responsive grid layout.
- **20 Included Animations:**
  1. Spinner Arc
  2. Bouncing Dots
  3. Pulse Rings
  4. Indeterminate Bar
  5. Skeleton Shimmer (avatar + multi-line placeholder)
  6. Orbit
  7. Equalizer Bars
  8. Square Morph
  9. Liquid Fill
  10. Dot Grid Wave
  11. Infinity Trail
  12. Flipping Square
  13. Gradient Ring
  14. Typing Dots
  15. Spoke Spinner
  16. Percent Bar (live percentage counter on hover)
  17. Chasing Squares
  18. Text Shimmer
  19. Battery Charge
  20. Bouncing Ball

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Hover over any card to preview its animation.
